Quadecare Hospital Management System
This is a management system scripted aNd designed on Microsoft Excel using VBA having  
Key features of the System
1. Patient Registration
2. Patient Retrival and Update
3. Appointment Scheduling
4. Appointment Update
5. Medical Record entry
6. Medical Record Update
7. Invoice creation
8. Bill update and printing 
The system is designed to simplify and streamline healthcare operations

Files included
1.  quadecare management system.xlsm:
This excel file contains the patient entry, appointment scheduling, medical record entry, invoice creation, patient data updates, appointment update, record update, invoice update and print, and validation sheets and interface
2.  Database file.xlms
3.  This Excel file is the linked file for database storage
4.  The following VBA scripts are also included
5.  patient entry script.bas
6.  Appointment Scheduling Script.cls
7.  Invoice creation script.cls
8.  Medical record entry script.cls
9.  Patient retrival and update.cls
10.  Appointment retrival and update.cls
11.  Billing updates and print.cls
12.  Medical record retrival and update.cls

    TOOLS USED
